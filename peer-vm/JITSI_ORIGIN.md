# Origin of jitsi-compose.yml

`jitsi-compose.yml` is the unmodified `docker-compose.yml` of
[jitsi/docker-jitsi-meet](https://github.com/jitsi/docker-jitsi-meet), release
`stable-11248`, licensed under the Apache License 2.0. It is vendored so the setup does not
depend on a download at deploy time. All our settings are in `.env` (generated by
`setup.sh`) and `peer-compose.yml`. To update Jitsi, replace the file with the compose file
of the new release and change `JITSI_IMAGE_VERSION` in `setup.sh`.
